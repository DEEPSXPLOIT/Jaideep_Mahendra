# Jaideep Mahendra — IT Support & Data Analysis

Personal portfolio featuring resume-based career experience and five interactive showcase projects.

## Features

- Black interface with gradient typography and responsive navigation
- English-only content
- Personalized 3D-style avatar with put-on/remove-sunglasses gestures and reduced-motion support
- Career timeline, impact metrics, certifications, and skills
- Five working browser demos with synthetic data and CSV exports
- Contact form and professional profile links

## Run locally

```bash
npm ci
npm run dev
```

Open http://localhost:3000. Use a recent Node.js version (Node.js 22 or newer).

```bash
npm run test:projects
npm run build
npm run start
```
